# Anninha's Command Center

Crie uma landing page moderna, profissional, responsiva e de alta conversão para a empresa:

ANNINHA CONSTRUÇÕES

Gestão de Compras e Acompanhamento de Obras

OBJETIVO DA PÁGINA

Converter visitantes em leads via WhatsApp e formulário de contato.

PÚBLICO-ALVO

Pessoas que estão construindo ou reformando e:

- trabalham durante o dia;

- não conseguem acompanhar a obra;

- não querem perder tempo com fornecedores;

- querem economizar nas compras;

- querem mais organização e controle;

- precisam de alguém para acompanhar compras, entregas e andamento operacional da obra.

POSICIONAMENTO

A ANNINHA CONSTRUÇÕES não deve parecer uma construtora tradicional.

O posicionamento principal deve ser:

“Gestão de Compras e Acompanhamento de Obras”

PROMESSA PRINCIPAL

“Sua obra sob controle, mesmo quando você não pode estar nela.”

SUBPROMESSA

“Mais controle. Melhores compras. Menos preocupação.”

==================================================

STACK / TECNOLOGIA

==================================================

Preferencialmente desenvolver com:

- React

- TypeScript

- Tailwind CSS

- Vite ou Next.js, dependendo do ambiente

- Lucide Icons

- componentes acessíveis

- mobile-first

- código limpo e organizado

- componentes reutilizáveis

Se estiver usando Lovable, adapte para a stack padrão do Lovable.

Não criar backend complexo inicialmente.

O formulário pode:

1. abrir o WhatsApp com mensagem pré-preenchida;

OU

2. preparar a estrutura para integração futura com Supabase.

==================================================

DESIGN

==================================================

Criar identidade visual sofisticada e confiável.

Estilo:

- construção civil premium;

- organização;

- confiança;

- proximidade;

- profissionalismo;

- aparência feminina sutil, sem parecer delicada ou infantil;

- evitar aparência de construtora pesada ou industrial.

Paleta sugerida:

- fundo off-white / areia clara;

- grafite;

- verde oliva ou verde musgo como cor principal;

- dourado/bege como cor secundária;

- branco para cards.

Usar bastante espaço em branco.

Evitar:

- excesso de gradientes;

- azul corporativo genérico;

- ícones caricatos;

- excesso de animações;

- layout poluído.

Tipografia:

- títulos fortes e elegantes;

- textos de alta legibilidade;

- aparência premium.

==================================================

RESPONSIVIDADE

==================================================

A página precisa funcionar perfeitamente em:

- celular;

- tablet;

- desktop.

Priorizar mobile.

No celular:

- CTAs grandes;

- menu simplificado;

- cards empilhados;

- botão flutuante de WhatsApp;

- textos curtos e fáceis de escanear.

13. FAQ

--------------------------------------------------

Criar accordion com:

Pergunta:

“A ANNINHA é uma construtora?”

Resposta:

“A ANNINHA CONSTRUÇÕES atua principalmente com gestão de compras e acompanhamento operacional de obras. O escopo específico depende do serviço contratado.”

Pergunta:

“Vocês substituem engenheiro ou arquiteto?”

Resposta:

“Não. Atividades que exigem responsabilidade técnica devem ser executadas ou validadas pelo profissional legalmente habilitado responsável pela obra.”

Pergunta:

“A ANNINHA compra os materiais?”

Resposta:

“Dependendo do plano, organizamos os pedidos após aprovação do cliente. Preferencialmente, o pagamento é feito diretamente pelo proprietário ao fornecedor.”

Pergunta:

“Vocês garantem o menor preço?”

Resposta:

“Não. Pesquisamos, comparamos e negociamos buscando boas condições considerando preço, prazo, pagamento e disponibilidade.”

Pergunta:

“Quantos fornecedores são cotados?”

Resposta:

“Normalmente buscamos até três propostas comparáveis por categoria, quando houver fornecedores disponíveis.”

Pergunta:

“Vocês acompanham entregas?”

Resposta:

“Sim, nos planos que incluem gestão de compras, acompanhamos o status das entregas junto aos fornecedores.”

Pergunta:

“Quantas visitas são realizadas?”

Resposta:

“A quantidade depende do plano contratado e da necessidade da obra.”

Pergunta:

“Quanto custa?”

Resposta:

“ANNINHA COTA a partir de R$ 290, ANNINHA COMPRAS a partir de R$ 990 por mês e ANNINHA GESTÃO a partir de R$ 1.990 por mês.”
